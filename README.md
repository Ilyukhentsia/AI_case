Это ИИ агент для помощи с поиском информации.
В данном репозитории ./chroma_db - сформированная база данных о МГТУ им. Н.Э.Баумана.

Если хотите создать свою базу данных, то в папку documents следует положить .pdf, .txt, .json файлы, а в текстовый документ ./code/urls.txt ссылки на сайты, которые хотите добавить в базу данных.
Далее активируете файл ./code/ingest.py из корневой папки проекта.
Поздравляю! Ваша база данных готова!

Чтобы активировать ИИ агента, активируйте из корневой папки проекта файл ./code/rag_agent.py и начните задавать интересующие вас вопросы.
